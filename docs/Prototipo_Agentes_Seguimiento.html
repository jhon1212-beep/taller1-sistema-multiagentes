Brechas que resuelve

✔ Información dispersa entre repositorios, tareas y documentos → vista unificada
✔ Revisión manual y periódica → recopilación automática de evidencias
✔ Retrasos detectados tarde → alertas tempranas de tareas estancadas
✔ Polizonaje detectado al final → Gini incremental por sprint
✔ Métricas aisladas (commits) → avance contextualizado
✔ Datos técnicos poco legibles → reportes resumidos para docente y estudiante
