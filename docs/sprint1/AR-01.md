# AR-01 — Contrato del módulo evidencias

## 1. Descripción

Se publicó el contrato del módulo `evidencias`, siguiendo el formato de `docs/arquitectura.md`: la entidad `Evidencia` (dominio puro), el puerto `FuenteEvidencia` y un adaptador falso (`FuenteEvidenciaFalsa`) con datos de ejemplo, para que `supervision` (Reyes) y el frontend (Mondragón) puedan programar contra el módulo sin esperar a que los agentes reales de GitHub, Notion y Drive estén conectados.

Código: `backend/app/modulos/evidencias/dominio.py`, `puertos.py`, `adaptadores/falso.py`
Pruebas: `tests/test_contrato_evidencias.py`

## 2. Criterios de aceptación

| N.° | Criterio | Resultado |
|---|---|---|
| 1 | `dominio.py` define la entidad `Evidencia` con sus 6 campos (fuente, id_externo, autor, fecha, descripción, proyecto). | Cumple |
| 2 | `puertos.py` define el contrato `FuenteEvidencia` que deben cumplir todos los adaptadores. | Cumple |
| 3 | `FuenteEvidenciaFalsa` devuelve evidencias de ejemplo y tiene prueba en verde. | Cumple — ver `TA-006_AR-01_pytest.png` |

## 3. Cómo se probó

```bash
cd backend
pytest -v ../tests/test_contrato_evidencias.py
```
