# TA-006 — Implementar Agente GitHub

## 1. Descripción

Se implementó el Agente GitHub como nodo de LangGraph, que extrae los commits del repositorio de un proyecto y los normaliza al esquema común de evidencia definido en `docs/modelo-de-datos.md` y `docs/arquitectura.md` (fuente, id_externo, autor, fecha, descripción).

El nodo reutiliza el cliente de solo lectura construido en EN-001 (`scripts/github_client.py`), al que se le agregó el método `commits_detallados()` para obtener el SHA completo de cada commit (el método original `commits()` lo trunca a 7 caracteres para lectura humana, pero el esquema de evidencia necesita el identificador completo).

Código: `backend/app/agentes/nodo_github.py`
Pruebas: `tests/test_agente_github.py`

---

## 2. Criterios de aceptación

| N.° | Criterio | Resultado | Evidencia |
|---|---|---|---|
| 1 | Recupera hasta 20 commits con autor, fecha, mensaje y SHA. | Cumple | `TA-006_salida_real.json` |
| 2 | 5 de 5 commits coinciden con la API. | _Pendiente de verificar contra el repositorio real_ | `TA-006_comparacion.png` |
| 3 | Las pruebas pytest del agente pasan. | Cumple | `TA-006_pytest.png` |

`docs/sprint1/evidencias/TA-006_salida_ejemplo.json` muestra el formato de salida con datos simulados (se generó con la API mockeada, igual que las pruebas unitarias). El archivo `TA-006_salida_real.json` de la tabla de arriba es la salida real contra el repositorio del equipo, que se genera en el paso 3 de la sección siguiente.

---

## 3. Cómo se probó

Las pruebas unitarias (`tests/test_agente_github.py`) simulan el cliente de GitHub, para que no dependan de red ni de un `GITHUB_TOKEN` y pasen igual en cualquier máquina o en CI. Verifican:

- que un commit crudo se normaliza correctamente al esquema común;
- que el nodo nunca pide más de 20 commits;
- que, si la API falla, el nodo devuelve un error controlado en el estado en vez de interrumpir el programa.

La verificación contra la API real (criterio 2) es manual: se ejecuta el nodo contra el repositorio del equipo y se comparan 5 commits de la salida contra lo que muestra GitHub en la pestaña *Commits*.

```bash
cd backend
python -m app.agentes.nodo_github
```

El repositorio por defecto es `jhon1212-beep/taller1-sistema-multiagentes`; se puede apuntar a otro con la variable `TA006_REPO`.
