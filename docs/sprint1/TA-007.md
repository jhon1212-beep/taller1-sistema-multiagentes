# TA-007: Adaptador y Agente Notion

## Descripción
Implementación del adaptador de la API de Notion y del nodo/agente de LangGraph para la extracción y normalización de tareas desde la base de datos de Notion hacia el esquema común de evidencias del proyecto.

## Criterios de Aceptación
- [x] Recupera las 20 tareas demo de Notion con las propiedades: Tarea, Responsable, Estado y Fecha límite.
- [x] 5 de 5 tareas coinciden exactamente en la comparación manual entre Notion y el JSON exportado.
- [x] Se registra un error controlado de autenticación (401/403) con token inválido sin generar evidencias.

## Cómo se probó
1. **Pruebas unitarias:** Se ejecutó `python -m pytest tests/test_agente_notion.py -v` pasando las 9 pruebas en verde.
2. **Ejecución contra base real:** Se ejecutó el agente generando el archivo `docs/sprint1/evidencias/TA-007_salida_real.json` con las 20 tareas procesadas.
3. **Verificación cruzada:** Se verificó visualmente en pantalla dividida que 5 tareas del JSON coinciden en nombre, responsable, estado y fecha límite con la tabla de Notion.
4. **Manejo de error controlado:** Se forzó el uso de un token inválido en PowerShell registrando la salida en `docs/sprint1/evidencias/TA-007_error_403.txt`.
